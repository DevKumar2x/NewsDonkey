# News App

## Overview
A modern news application for browsing and reading the latest news articles.

## Features
- Browse news from multiple sources
- Search articles by keyword
- Filter by category
- Save favorite articles
- Dark mode support

## Installation
```bash
npm install
```

## Usage
```bash
npm start
```

## Requirements
- Node.js 14+
- npm or yarn
